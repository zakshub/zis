## Low information or currently empty repositories

Several repositories are empty or contain only starter code. They should not be treated as intelligence merely because they exist. ZIS must evaluate capability from actual contracts, evidence and implementation.

Examples currently showing little or no immediately reusable intelligence include stockbot, 10-projects, aimehfil, doctors, dosra-blog, dosra-such, frontend-playground, jsprojects, muselab, ng-practise, practise-jonas, pulse, tw, zaks, zaks.github.io and zuhaib.pro.

## Repository selection rule

ZIS should use a repository only if it contributes one of these:

1. A specialist intelligence
2. A reusable service or tool
3. A verified dataset
4. A durable architecture pattern
5. A workflow that reduces new build cost
6. A test or safety pattern

Existence alone is not a reason to integrate.
