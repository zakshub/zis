# Memory, Evidence and Learning

## Memory classes

1. Core principles
Durable operating rules.

2. Pattern memory
Repeated cognitive, writing, taste, decision and behavior patterns.

3. Preference memory
Contextual preferences with timestamps and confidence.

4. Project memory
Temporary project state.

5. Evidence memory
Source records, observations and provenance.

6. Experimental memory
Unverified hypotheses.

7. Deprecated memory
Superseded or rejected models retained for audit.

## Evidence states

Observation

Claim

Inference

Hypothesis

Confirmed pattern

User correction

Counterevidence

Deprecated conclusion

## Required metadata

Every durable learning should record source, source type, time, scope, confidence, supporting evidence, counterevidence, version and promotion status.

## Learning lifecycle

Observe

Capture

Classify

Validate

Compare against existing knowledge

Detect duplication or conflict

Promote or reject

Apply

Review

Decay confidence when stale

Supersede when stronger evidence appears

## Consolidation cycle

ZIS should periodically consolidate recent evidence instead of promoting every event immediately.

The consolidation process asks:

1. What repeated?
2. What changed?
3. What was noise?
4. Which assumption weakened?
5. Which pattern strengthened?
6. Which new connection is useful?
7. What should be forgotten from active cognition while remaining auditable?

## Temporal intelligence

Patterns are time scoped. The system must support changing tastes, changing priorities and changing behavior instead of treating an old statement as permanent identity.
