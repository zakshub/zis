# ZOS Asset Inventory for ZIS

This is the first reviewed inventory of the existing ZOS repository as a migration source.

## Strong reusable architecture already present in ZOS

1. Kernel concept with constitution, evidence rules, permissions and human authority.
2. Capability catalog and task routing.
3. Decision, writing, product, design and blind spot models.
4. Evidence hierarchy and provenance aware thinking.
5. Memory and model update concepts.
6. Local and VPS runtime separation.
7. Private data outside Git.
8. Human approval before important external execution.
9. CLI and authenticated web workspace patterns.
10. Versioning and audit oriented operation.

## Strong reusable cognitive evidence

The ZOS personal constitution contains explicit answers and models about values, decision sequence, justice, forgiveness and memory, power, anonymity, money, creativity, learning, stress, relationships, emotional expression, humor, film taste and personality test handling.

These are valuable as evidence, but ZIS must migrate them through identity protection, provenance and confidence rules rather than copy them as unquestionable truth.

## Existing ZOS capability material

The ZOS repository contains a large skill catalog covering systems thinking, product thinking, UX architecture, UI design, design systems, healthcare UX, design to code, AI product building, agent workflows, brand design, creative direction, game UI, storytelling, comics, teaching, research, protocol architecture, automation, RTL localization and more.

For ZIS, many of these should become routing references to specialist repositories rather than duplicated internal skills.

## ZOS material to retain as historical source

1. Original source documents.
2. Human answers.
3. Evolution timeline.
4. Evidence rules.
5. Past decisions and contradictions.
6. Writing corpus references.
7. Blind spot candidates.
8. Runtime and security lessons.

## ZOS material requiring separation

1. Direct identity data.
2. Employer or company references.
3. Public identity branding.
4. Design intelligence now owned by Designer.
5. Image intelligence now owned by Studio.
6. Product specific implementation that is not cognitive infrastructure.

## Migration objective

ZOS becomes one major ancestor and evidence source of ZIS, not the runtime foundation by default and not a codebase to clone wholesale.
