# System Definition

ZIS is an indefinite cognitive operating system.

Indefinite means the system has no declared final intellectual form. It can acquire evidence, revise models, add or retire capabilities, create new adapters, change implementation technologies and preserve continuity over time.

## Identity model

The public and canonical identity is ZIS.

The core must not require real name, face, employer, company, precise address or other direct identity data.

Knowledge may be personal in pattern and provenance while identity remains abstracted.

## Canonical language

English is the canonical language for architecture, production specifications, schemas, roadmaps and implementation documentation.

ZIS itself is multilingual. Urdu and Roman Urdu are first class interaction languages. More languages may be added through adapters.

## Single owner assumption

Version 1 assumes one human owner. If ZIS later becomes a product for other people, each person receives an isolated cognitive instance. Shared knowledge can exist separately but must never collapse private cognitive models into one shared personal brain.
