# Specialist Intelligence Router

ZIS must not duplicate deep specialist knowledge when a dedicated intelligence already exists.

## Routing principle

ZIS decides what kind of thinking is required.

A specialist intelligence performs deep domain reasoning.

A tool performs execution.

ZIS then synthesizes the result into the wider cognitive context.

## Router contract

For every specialist entry ZIS must know:

1. Purpose
2. Capabilities
3. Inputs required
4. Outputs produced
5. When to use
6. When not to use
7. Confidence and maturity
8. Repository or service location
9. Security boundary
10. Fallback path

## Anti duplication rule

If Designer owns design intelligence, ZIS stores only routing knowledge and cross domain cognitive patterns. It does not copy the full design brain into ZIS.

If Studio owns image intelligence, ZIS stores only routing knowledge and task context needed for orchestration.

The same rule applies to all future specialist intelligences.
